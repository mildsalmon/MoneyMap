# 통계 첫 버전 검증

최종 검증: 2026-11-05 · v0.12.0.0 · `feature/statistics-overview`. [설계·집계 계약](../designs/statistics-overview.md).

## 범위와 판단

사용자의 판단 위임에 따라 첫 P2 통계를 구현했다. 기간 수입·지출과 기간말 자산·부채·순자산을 구분하고 월별 추이·정확한 표·계정 그룹 구성을 제공한다. 전체 장부의 수익·비용에는 투자 손익도 포함되며 생활비·현금흐름·저축률로 해석하지 않는다. 계정별 상세·태그·기간 비교는 TODO 후속으로 남겼다. 실제 사용자 DB를 수정하지 않았으며 스키마·의존성 추가는 없다.

## 리뷰와 시각 확인

백엔드와 프런트는 같은 모델의 독립 문맥에서 검토했다. 설계 검토자는 기존 문맥으로 적대적 구현 검토를 수행했다. 외부 모델 리뷰는 수행하지 않았다. 발견한 SQLite 중간 합 오버플로, 브라우저 지역의 건너뛴 날짜, 모바일 긴 그룹명 잘림을 수정하고 집중 회귀 테스트를 추가했다. 미해결 발견 사항은 없다.

데스크톱·390px 모바일 스크린샷에서 Ink Ledger 토큰, 기간 조건·요약 금액·월별 표를 확인했다. 월별 표는 내부 가로 스크롤을 제공하며 계정 구성의 금액은 화면 안에 표시한다. 스크린샷은 테스트 임시 결과에 저장하고 저장소에는 포함하지 않는다.

## 한계

KRW 실제 기장만 조회하며 비원화 분개 또는 비원화 계정을 포함한 거래 전체를 제외한다. 기간 전 거래도 기간말 잔액에 영향을 주므로 제외 건수에 포함한다. 계정 이름·계층은 현재 상태다. API 숫자가 안전 정수 범위를 넘거나 SQLite SUM 중간 값이 넘으면 오류를 표시하며 반올림한 금액을 제공하지 않는다. 원장 편집·자동 분류·환산·전망은 통계 조회에 포함하지 않는다.
