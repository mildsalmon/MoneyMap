## 구현

- 자동 선택·저장 후 유지된 계정은 새 아이템의 추천으로 갱신하고, 직접 선택한 계정은 차변·대변 각각 보호한다.
- 추천 대기 중 저장 버튼과 submit 처리에 같은 판단을 적용한다. 양쪽 모두 직접 선택한 경우에는 유효한 거래를 저장할 수 있다.
- 실제 조회 요청에 5초 제한을 적용한다. 실패·시간 초과 시 계정 값을 보존하고 재조회 버튼을 제공한다.
- 실행취소 성공 시 기존 값을 보호한다. 화면 재진입과 늦게 도착한 응답에서도 보호하고, 아이템 변경이나 명시적 재조회로 해제한다.

백엔드 경고는 기존 테스트 클라이언트의 httpx 사용 중단 예정 안내이며, 빌드에는 큰 청크 안내가 있다. 두 명령 모두 성공했다.

## 범위 및 미완료 단계

별도 Orca 작업 공간과 테스트 포트 8997/5407, 임시 E2E DB를 사용했다. 원래 작업 공간의 미완료 변경과 실제 거래 DB는 수정하지 않았다. 백엔드 API·DB 스키마 변경은 없다.

공식 gstack 코드 리뷰, 수동 브라우저 QA, 푸시·PR·머지는 수행하지 않았다. 자동 테스트 통과를 해당 단계의 완료로 간주하지 않는다.
