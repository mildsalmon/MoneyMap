# 로컬 CSV 메모 교정 설정

개인정보가 포함될 수 있는 메모 교정은 `backend/local/legacy-row-corrections.json`에 보관한다. `backend/local/`은 Git 제외 대상이며 공개 저장소에 추가하지 않는다. 이 파일은 사용자 데이터이므로 장부 백업과 별도로 안전하게 보관한다.

기존에 승인된 교정 두 건은 현재 로컬 파일로 옮겼다. 실제 장부의 메모나 원본 CSV는 다시 쓰지 않았다.

형식은 원본 파일의 SHA-256 → 원본 CSV 행 번호(헤더는 1행) → `[교정 전 문자열, 교정 후 문자열]`이다. 다음은 합성 예시다.

```json
{
  "원본-파일의-sha256": {
    "2": ["합성 오타", "합성 교정"]
  }
}
```

이관 스크립트는 이 경로를 자동으로 읽는다. 경로는 실행 디렉터리와 무관하다. 원본 해시가 같은 교정만 적용하고 `raw_memo`는 그대로 보존한다. 파일이 없거나 해당 해시가 없으면 원문 메모를 사용한다. 다른 컴퓨터에서 이관할 때 승인된 교정도 재현하려면 이 로컬 파일을 안전하게 별도로 복사해야 한다. 기존 이관 거래는 재이관 시 건너뛰므로 현재 수정된 메모를 덮어쓰지 않는다.

회귀 검증은 합성 문자열과 임시 파일만 사용한다: `backend/tests/test_legacy_import.py::test_private_corrections_are_source_scoped_and_preserve_raw_memo`.
