# 현금성 외화 원장

**외화 원장**에서 통장 명세서의 실제 출금액 또는 입금액을 수수료까지 포함해 입력한다. 외화 수량, 거래환율, 그 환율의 기준일과 출처를 함께 기록한다. 실제 원화 원금은 매수 때 출금액에서 수수료를 빼고, 매도 때 입금액에 수수료를 더해 구한다. 은행이 확정한 금액에는 단수 차이가 있을 수 있어 입력 환율을 곱한 값으로 원금을 덮어쓰지 않는다.

## 기장과 관리 보고

환전 ID 하나에 원화 거래와 외화 거래가 연결된다. 원화 거래에는 통장, 원화 환전 상대계정, 수수료 비용이 들어간다. 외화 거래에는 해당 통화의 외화 현금과 환전 상대계정이 들어간다. 각 거래 안에서 차변과 대변이 일치한다. 외화 수량은 Money의 통화별 최소 단위 정수로 보관한다. 환전 수정은 두 거래와 원가를 함께 갱신하며, 이후 매도에서 보유 수량이 음수가 되는 수정은 취소한다.

관리 보고의 원가 단위는 통화별 외화 현금 계정이다. 거래일 순서대로 계산하며 같은 날에는 환전 ID 순서를 따른다. 매도 때 직전 잔여 원가에 매도 수량의 비율을 곱해 원 단위로 반올림하고 남은 원가를 다음 매도로 넘긴다. 전량 매도하면 잔여 원가는 0원이다. 수수료는 매수·매도 모두 별도 비용이다. 실현 손익은 매도 원금에서 배분 원가를 뺀 값이고 미실현 손익은 평가액에서 잔여 원가를 뺀 값이다.

평가일 당일 사용자가 확정한 환율로 계정별 원통화 잔액을 환산한다. 가장 가까운 날의 환율이나 거래환율을 가져오지 않는다. 당일 환율이 없는 잔액은 미평가로 표시하고 평가한 외화 소계와 원화 순자산을 구분한다. 과거 외화 분개도 원통화로 보이며 취득원가를 알 수 없는 계정은 손익을 비워 둔다. 기존 대시보드·통계·시나리오는 원화 장부 기준을 유지한다.

## 과거 USD 구매 선택 이관

v16 스키마 설치는 기존 거래를 그대로 보존한다. 선택 이관은 CSV 지문·파일명·행 번호로 출처를 확인하고, 원본 차변이 ‘비용 / 원화에서달러로환전’, 대변이 자산 계정인 행만 대상으로 삼는다. 원본 날짜와 금액도 현재 원화 분개와 일치해야 한다. 계정 이름을 변경해도 대상 행은 그대로다. 날짜·통장·출금액을 원본에서 가져오고 사용자가 USD 수량과 거래환율·출처·수수료를 확정한다. 미리보기에서 통장·기존 비용·수수료·상대계정·외화 현금의 전후 잔액을 확인한다.

확정할 때 쓰기 잠금 안에서 원본과 잔액을 다시 확인하고 DB 옆의 backups 디렉터리에 SQLite 온라인 백업을 저장한다. 출금은 원본에 있으므로 원화 분개에서 기존 비용을 환입하고 수수료만 비용으로 남긴다. 저장 후의 통화별 잔액이 미리보기와 일치해야 커밋한다. 환전 내역에서 원본 거래 번호, CSV 파일·행·지문과 백업 파일명을 확인할 수 있다.
