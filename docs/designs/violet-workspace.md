# Violet Workspace

2026-11-15 · 사용자가 제공한 보라색 사이드바와 카드형 대시보드 이미지를 기준으로 디자인을 바꿔 달라고 요청했다. gstack design-consultation으로 방향을 잡고 에이전트 3명과 디자인 방향/독립 화면 검토, 공통 셸, 대시보드 구현을 나눴다. [DESIGN.md](../../DESIGN.md)가 현재 디자인 기준이다.

- 제공 이미지를 선택한 방향으로 삼는다. 색·간격·반응형 수치는 코드와 한국어 가독성에 맞춰 판단했다. 별도 경쟁사 조사나 외부 모델·AI 이미지 생성은 하지 않는다.
- 라벤더 배경, 둥근 작업 공간, 단색 보라색 184px 메뉴와 흰 활성 메뉴, 흰색 카드와 미세한 그림자를 사용한다. 기존 메뉴 8개와 실제 검산·백업 상태는 유지한다.
- 대시보드에는 순자산·이번 달 수입·지출·순수입 4개 지표, 실제/미래 자산 흐름, 반복 규칙 수·실제 화면으로 이동하는 버튼을 배치한다. 진행률·알림·프로필·가짜 데이터는 추가하지 않는다.
- 계정 잔액과 월별 지출은 하단에서 모두 확인한다. 보관 계정·환불·음수·합산 범위·계정 링크·조회/수정 복귀·차트 계단 곡선과 키보드 탐색을 유지한다.
- 데스크톱은 지표/차트와 라벤더 보조 영역을 나란히 배치한다. 1024px에서는 보조 영역을 아래로, 1200px 미만에서는 하단 계정·지출 표를 한 열로 쌓는다. 720px 이하에서는 상단 3열 메뉴와 지표 2열·한 열 콘텐츠로 바꾼다. 메뉴와 대시보드 조작부는 44px 이상이다.
- 모바일 차트는 고정 viewBox를 지나치게 축소하면 축 글자가 읽히지 않는다. 차트의 SVG 영역만 920px 이상으로 유지해 자체 수평 스크롤로 탐색한다. 범례·표 보기·스크롤 안내는 바로 보이게 한다. 차트 계산과 선형 보간은 바꾸지 않는다.
- `.main`은 계속 콘텐츠의 세로 스크롤과 수정 복귀 위치를 소유한다. 낮은 데스크톱에서 메뉴가 잘리지 않도록 사이드바만 별도로 스크롤할 수 있다.
- 실제 앱 화면을 1440/1024/720/390px에서 검사하고 1440/390px 캡처·HTML 프리뷰를 로컬 gstack 디자인 아티팩트 폴더에 보관한다. 캡처는 검증용 합성 데이터이며 사용자 장부를 사용하지 않는다.

구현 기준은 `f2d28d0`이며 `feature/violet-dashboard`에서 작업한다. 이전 계정 조회·잔고 기능과 통계 PR #18의 의존성은 그대로다. 이 작업은 로컬 구현이며 ship·main 병합·배포는 별도 요청 단계다.
